# Create detailed study notes

Use this when you want a clear, detailed Markdown reference from a lesson or trusted source. These notes are suited to saving and revisiting in your learning repository. For a colorful page to copy by hand, use [handwritten visual notes](09-visual-notes.md).

## Ask for notes

Invoke `study-notes` or say:

> Read `skills/study-notes/SKILL.md` and follow it. Create detailed Markdown study notes about [topic] from [lesson, files, or sources]. Explain the core ideas, define key terms, include a worked example and common mistakes, and add review prompts. Preserve source links and label anything uncertain. Draft it for review before saving.

If the notes should be saved in a learning repository, agree on the exact path and tracking policy:

> Save the approved notes as Markdown at [path] in my learning repo. Do not put personal journal reflections or my quiz attempts in the notes.

## Review and use them

Check that the explanations match what you studied, examples are useful, and source links support the claims. Ask for corrections before saving. Use the Teacher for a deeper explanation or a practice check; the study-notes workflow should not claim that reading the notes proves mastery.

To close Study Notes mode, ask for a final consolidated Markdown draft, review it, and save only to the agreed path.
