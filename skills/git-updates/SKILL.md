# Git updates

Follow the learner's agreed Git policy. Preparing files does not itself authorize committing or pushing.

Confirm repository, branch, intended files, and whether the request covers review, staging, commit, push, or only some of those. Inspect status and diffs. Flag private learner data, secrets, generated files, and unexpected changes.

Before committing or pushing, summarize exactly what will be included and the destination. Exclude journal or private data unless the learner explicitly wants it tracked. Ask for specific approval unless the instruction explicitly authorizes the action. Use the learner's agreed message style. Do not invent remotes or change Git configuration without authorization.

After action, report the commit, push destination, and result. Do not silently retry a broader operation. Never delete history, force-push, or rewrite commits unless the learner explicitly requests that exact action.
