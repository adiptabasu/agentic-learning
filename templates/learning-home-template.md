# Learning home

Copy this file to an agreed location in the learning repository, commonly `LEARNING.md`, only after deciding that learning records should live in that repo. Replace the placeholders with paths that exist in the agreed structure. Keep private information out of tracked files unless the learner explicitly chooses to share it.

## How to resume

When asked to continue learning in this repository, read this file and then the linked active goal, plan, progress journal, and latest session note. Summarize the current state and ask whether the learner wants to continue or change direction before teaching. If this file or a linked record is missing, ask rather than inventing progress.
